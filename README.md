# SnapEnvoice — Marketing Website

> **Launch mode.** The site now sells the live iOS app — the waitlist is retired
> (the `/api/waitlist` routes remain but are unlinked). On App Store approval,

```bash
npm run dev      # http://localhost:3000  (works with zero config)
npm run build    # production build
```
